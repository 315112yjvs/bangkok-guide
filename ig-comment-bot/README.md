# 留言小幫手（FB / IG 抽獎）

在指定的 **Facebook 或 Instagram** 留言串自動「回覆」隨機食物英文 + 活動 hashtag，讓同一串的回覆數衝高。開哪個網站就自動切換對應邏輯（FB 用 Enter 送出、IG 用發佈鈕）。

## 安裝
1. Chrome 開 `chrome://extensions`
2. 右上角開「開發人員模式」
3. 點「載入未封裝項目」，選這個 `ig-comment-bot` 資料夾

## 使用
1. 打開活動貼文，把留言區展開到看得到你要洗的那一串
2. 面板最上面選 **平台**（自動 / FB / IG，通常維持「自動」即可）
3. 點 **🎯 選取目標留言** → 再點頁面上那則留言（點在留言文字上）
4. 需要標記自己就填 **每則 @ 的帳號**；設定 **Hashtag / 間隔 / 休息 / 目標則數**
5. 按 **▶ 開始**；要停就按 **■ 停止**

留言格式：`🍕 Pizza #LINEMANWongnaiUsersChoicexInnOngsa`（每則隨機食物+emoji、上一則用過的食物不會馬上重複，降低被判洗版）。

## 分批休息（防鎖重點）
為了不要在短時間內留太多、太密而被鎖帳號，內建**兩層休息**機制，模擬真人節奏：

| 層級 | 觸發條件 | 休息時間 | 對應欄位 |
|---|---|---|---|
| 每則間隔 | 每送一則 | 30~90 秒（隨機） | 最短/最長間隔(秒) |
| 小批休息 | 每 **10** 則 | 5~8 分鐘（隨機） | 每批留言幾則後休息 + 休息最短/最長(分) |
| 大休息 | 每 **50** 則 | **15** 分鐘 | 大休息門檻(則) + 大休息(分) |

- 以上數字都是**預設值**，面板可自行調整。
- **大休息優先於小批休息**：滿 50 則時直接休 15 分鐘，並把小批計數一起歸零，不會休完馬上又觸發 5 分鐘小休息。
- 大休息會加 0~90 秒隨機抖動（例如 15:00~16:30），不會每次都精準 15 分，較像真人。
- 小批填 **0 = 不分批**、大休息門檻填 **0 = 關掉大休息**，即可退回「只用秒數間隔」的舊行為。
- log 每則會顯示「本批 3/10」進度，休息時會跳出 `😴`（小批）或 `🛌`（大休息）提示。

## 面板功能
- **平台切換**：自動偵測，也可強制 FB / IG
- **每則 @ 的帳號**：FB 填「顯示名稱」（會自動跑下拉選單選你的帳號）；IG 填「@handle」（送出後自動連結）
- **分批休息**：小批（每 N 則休息幾分鐘）＋大休息（每 M 則休息更久），詳見上方「分批休息」
- **目標則數**：達到就自動停（0=不限）
- **連續 5 次失敗自動停**：避免空送或被盯上
- **設定自動記憶**：hashtag、@帳號、間隔、休息設定、平台都存在瀏覽器，重整不會清空

## FB 補充
- FB 建議先手動按一次目標留言的「回覆」把回覆框叫出來，成功率更高。
- FB @提及需要跑下拉選單，過程請不要手動點進留言框打字，避免干擾。
- @帳號要填「顯示名稱」（例：Laurent Saint），程式會自動打字叫出選單、選你的帳號變藍字。

## 注意事項（重要）
- FB / IG 都禁止自動化操作，短時間洗大量留言**很可能被限流或封號**。間隔別調太短，30~90 秒相對安全，並搭配分批休息（每 10 則休 5~8 分、每 50 則休 15 分）降低風險。
- 建議用小帳測試，別拿主帳跑。
- 前端改版時「回覆／發佈」按鈕可能失效，看面板 log；失效就回報我更新 selector。
