# City Recital Hall 搶票助手

針對 **GMMTV FANDAY 34 IN SYDNEY**（City Recital Hall，2026/9/19）寫的 Chrome 擴充功能。

- 開賣：**2026/8/6（三）10:00 AEST**（台灣時間 08:00、泰國時間 07:00）
- 售票系統：**Tessitura TNEW** — `tickets.cityrecitalhall.com`
- 票價：S $330／A $300／B $230／General $100，另加 $8.50 手續費
- 兩場：14:00（First-Khaotung）、20:30（Sea-Keen）
- 特典（Special Benefits）走 Ticketmelon，**不在**這個外掛範圍內

## 這個站的兩道關卡

實際去測過站台，有兩件事決定了外掛怎麼寫：

**1. Queue-it 候位室**
網址會帶 `queueittoken=e_crh247~rt_safetynet`，代表開賣時會有虛擬排隊室。
排隊順序是進場時隨機決定的，**重整分頁 = 失去位置**。所以外掛偵測到排隊頁時會
進入安全模式：完全不動作，只顯示前面還有幾人，輪到你時發出通知＋提示音。

**2. Imperva Incapsula 機器人偵測**
我用 curl 直接打他們的 API 立刻被擋。所以外掛**不自己發 API 請求**，
全部走真實分頁的 UI 操作，用你自己的 cookie 和瀏覽器指紋，行為跟真人一樣。

## 加速關鍵：`?z=0`

TNEW 預設是畫布選位（SYOS，SVG 座位圖，載入慢）。網址加上 `?z=0` 會切換成
**純 HTML 的「最佳座位」表單** — 票區是 radio、張數是 select，
一次 click + 一次 change + 一次 submit 就結束，比點座位圖快非常多。

外掛預設走這條路（可在設定關掉）；如果該場次不提供最佳座位模式，會自動退回
畫布選位，改成自動點可選座位。

## 安裝

1. Chrome 開 `chrome://extensions`
2. 右上角打開「開發人員模式」
3. 「載入未封裝項目」→ 選這個 `crh-grabber` 資料夾

## 開賣前準備（很重要）

1. **先登入** `tickets.cityrecitalhall.com`，確認帳號正常、地址資料都填好了。
   外掛不會、也不該碰你的帳號密碼 — 沒登入的話搶到票也留不住。
2. 信用卡放手邊。付款頁**完全不自動化**，卡號要你自己輸入。
3. 提前 10 分鐘打開分頁按「開始」，讓它接管倒數。

## 設定說明

| 欄位 | 說明 |
|---|---|
| 目標場次網址 | 開賣後長 `https://tickets.cityrecitalhall.com/{節目ID}/{場次ID}`。現在還沒上架，可留空 |
| 自動搜尋 | 留空網址時，去 `/events/` 用關鍵字（預設 `GMMTV`）找場次，找到自動跳過去 |
| **場次關鍵字** | **兩場卡司不同，一定要填**。填 `2:00pm`（First-Khaotung）或 `8:30pm`（Sea-Keen） |
| 開賣時間 | ISO 格式含時區，預設 `2026-08-06T10:00:00+10:00` |
| 票區優先順序 | 逗號分隔，依序嘗試。例：`S, A, B, General` |
| 張數／最少可接受 | 想要 2 張但只剩 1 張時，「最少可接受」設 1 就會先搶下來 |
| 票種關鍵字 | 一個票區有多種票價時用（如 `Standard`）。留空＝取第一個 |
| 重試間隔 | 預設 900ms，另有隨機抖動避免固定節奏被判定為機器人 |

票區比對用「完整字詞優先」的方式：`S` 只會對到 `S Reserve` 這種獨立的 S，
不會誤中 `Standing`、`Seating`。

### 為什麼場次關鍵字非填不可

TNEW 的 `/{節目ID}` 網址**本身就是第一場的購票頁**，不是節目索引頁；換場次的 UI
是一排 `<button value="目標網址">August 15, 2026 2:00pm</button>`。也就是說你一進去
就站在「某一場」上，而那一場不見得是你要的。

所以只要偵測到多個場次而你沒填關鍵字，外掛會**直接停下來通知你**，
而不是自作主張挑一場 — 搶到錯的場次比沒搶到更麻煩。

## 執行流程

```
按下開始
  ↓ 校正伺服器時間（本機時鐘差幾秒就會早開/晚開）
  ↓ 倒數到開賣
  ↓ [有排隊室] → 安全模式，不動作，輪到了才通知
  ↓ 進入場次頁 → 自動切 ?z=0
  ↓ 依優先順序挑票區 → 設定張數 → 等 Purchase 解鎖 → 送出
  ↓ 進購物車 → 通知＋提示音＋把分頁拉到前景
  ↓ 導到結帳頁後【停止】— 付款你自己來
```

失敗會依設定的間隔重試，超過上限（預設 25 分鐘）自動停。

## 明確不做的事

- 不儲存、不填入帳號密碼
- 不填信用卡、不按最後的付款送出鍵
- 不繞過 CAPTCHA、不偽造瀏覽器指紋
- 排隊室內不重整、不做任何插隊嘗試

搶票畢竟是跟其他真人搶，這個工具只是幫你把「選票區、填張數、按按鈕」這幾秒
壓縮掉，不會讓你插隊。City Recital Hall 的條款也寫明他們是唯一授權售票方，
搶到的票請自己用，別轉賣。
